## मोबाइल से वेबसाइट को free में publish करने का तरीका
1. इस ZIP को अपने फोन में डाउनलोड करके Extract करें (Files app में ZIP पर tap करें)।
2. GitHub.com पर account बनाकर नया repository बनाएं और extracted project की files upload करें।
3. Vercel.com पर GitHub से sign in करें और इस repository को **Add New Project** से import करें।
4. Framework auto-detect होने दें और Deploy दबाएं। अगर Vercel कोई environment variable मांगे तो उसे अंदाज़े से न भरें—deployment settings के अनुसार configure करना होगा।
5. Deploy पूरा होने पर मिलने वाला `vercel.app` link आपकी वेबसाइट का public link होगा।

नोट: ZIP में मौजूद project का build/deploy आपके hosting account पर किए बिना live public URL नहीं बनता। Portfolio में 10 high-resolution sample wedding photos पहले से शामिल हैं। अपनी असली client/wedding photos उपलब्ध होने पर इन्हें अपनी original photos से replace कर देना, ताकि वेबसाइट आपका वास्तविक काम दिखाए।
